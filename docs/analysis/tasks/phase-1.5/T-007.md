## Context

Ship two canned demo scenarios: **General business** (CRM, Finance, Projects — Tier-2
coverage) and **NGO** (Fundraising, Sponsorship — Tier-3a coverage). Scenarios are
selectable via the CLI (T-006) and admin UI (T-008).

- Phase file: `../../roadmap/phases/phase-1.5-bridge.md` §1.5.7
- Legacy reference: `docs/roadmap/ROADMAP.md` §1.5.7 item 3
- Depends on: T-005, T-006.

## Acceptance criteria

- [ ] `DemoScenario` contract declares name, description, required modules, seed actions
      per module.
- [ ] General scenario seeds: ~20 contacts, a CRM pipeline with leads across stages,
      sample Finance entries, one Project with tasks.
- [ ] NGO scenario seeds: ~30 donor contacts, two campaigns, recurring donations,
      sponsorship pairings.
- [ ] Locale-neutral names/data or fully translated keys (no hardcoded user-facing
      strings).
- [ ] Unit tests per scenario.

## Technical notes

- Scenario files live in each module's infrastructure layer under
  `DemoData/<scenario>.cs`; the orchestrator picks them up via the module's
  `SeedDemoData` implementation.
- NGO scenario gracefully skips if Fundraising/Sponsorship modules are not yet installed
  (they ship in Phase 3a).
