## Context

Extend Contacts export with custom field selection, date range filter, and vCard format
support. Today's export only dumps a fixed set of core fields as CSV/Excel.

- Phase file: `../../roadmap/phases/phase-1.5-bridge.md` §1.5.6
- Legacy reference: `docs/roadmap/ROADMAP.md` §1.5.6 item 3

## Acceptance criteria

- [ ] Export dialog lets user pick fields (core + custom fields) via multi-select.
- [ ] Date range filter applies to `CreatedAt` or `UpdatedAt` (user picks).
- [ ] Formats: CSV, Excel, vCard (.vcf).
- [ ] Large exports run as Hangfire job; user notified via Notifications when ready.
- [ ] Locale-aware formatting (Phase 1.5.3 `ILocaleContext`) for dates and numbers.
- [ ] Unit tests per format; integration test for large-export async path.
- [ ] Locale: `lockey_contacts_export_*` keys in en + tr.

## Technical notes

- Reuse ReportExportService pipeline where possible; vCard is new output format.
- vCard 3.0 per RFC 2426.
