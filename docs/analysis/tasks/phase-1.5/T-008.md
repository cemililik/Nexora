## Context

Expose the demo loader in the admin UI so non-CLI users (sales, support, QA) can
provision a demo tenant from the browser.

- Phase file: [`../../../roadmap/phases/phase-1.5-bridge.md`](../../../roadmap/phases/phase-1.5-bridge.md) §1.5.7
- Legacy reference: `docs/roadmap/ROADMAP.md` §1.5.7 item 4
- Depends on: T-005, [T-029](T-029.md) (registry — replaces the original T-007 dependency after the T-007 split).

## Acceptance criteria

- [x] Button on the platform-admin "Tenants" page (TenantDetailPage), permission-gated
      (`platform.tenants.create_demo`).
- [x] Dialog collects scenario name (dropdown). Currently hardcoded to the two
      foundation scenarios (`general` / `ngo`); dropdown becomes registry-driven
      once [T-029](T-029.md) (`DemoScenario` registry; the implementable slice
      of the superseded T-007 split) lands.
- [x] Submit calls `POST /identity/tenants/demo` — permission-gated on the
      new `platform.tenants.create_demo` platform-scope permission. Path lives
      under `/identity/tenants/` to match existing tenant endpoints; the
      permission scope (not the path prefix) is the auth gate.
- [ ] **[deferred]** Progress shown via a polling hook; completion sends a
      Notification. Intentionally **deferred** — the endpoint currently runs
      `IDemoDataSeeder.SeedAsync` **synchronously** and returns the full
      per-module summary in the same request (seed takes seconds, not
      minutes). No polling / Hangfire wrap needed today. Per
      [documentation-style.md](../../standards/documentation-style.md)
      discipline (Definition of Done visibility), AC#4 stays unchecked and
      the deferral reason lives here so the `-> done` automation does not
      gloss over it. Plan for a future `async=true` Hangfire mode if
      T-007 scenarios grow heavy (see status log).
- [x] Uses shared components per UX_UI_STANDARDS §9 (FormField, shadcn Select,
      Dialog primitives).
- [x] Locale: `lockey_platform_tenants_demo_*` keys in en + tr bundles
      (17 keys each, parity verified at code review).

## Technical notes

- Endpoint must be platform-scope (per Phase 1.5.2) — hidden from tenant admins.
- TanStack Query mutation + invalidation per API_INTEGRATION_STANDARDS §8.
