## Context

Expose the demo loader in the admin UI so non-CLI users (sales, support, QA) can
provision a demo tenant from the browser.

- Phase file: `../../roadmap/phases/phase-1.5-bridge.md` §1.5.7
- Legacy reference: `docs/roadmap/ROADMAP.md` §1.5.7 item 4
- Depends on: T-005, T-007.

## Acceptance criteria

- [ ] Button on the platform-admin "Tenants" page, permission-gated
      (`platform.tenants.create_demo`).
- [ ] Dialog collects tenant slug + scenario name (dropdown populated from registered
      `DemoScenario` instances).
- [ ] Submit calls a `POST /platform/tenants/demo` endpoint that enqueues the Hangfire
      job.
- [ ] Progress shown via a polling hook; completion sends a Notification.
- [ ] Uses shared components per UX_UI_STANDARDS §9 (FormField, ConfirmDialog,
      LoadingSkeleton).
- [ ] Locale: `lockey_platform_tenants_demo_*` keys in en + tr.

## Technical notes

- Endpoint must be platform-scope (per Phase 1.5.2) — hidden from tenant admins.
- TanStack Query mutation + invalidation per API_INTEGRATION_STANDARDS §8.
