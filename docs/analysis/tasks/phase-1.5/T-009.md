## Context

Demo tenants accumulate over time (sales demos, QA runs). Provide a command and matching
admin action to remove demo content — or the entire demo tenant — idempotently.

- Phase file: `../../roadmap/phases/phase-1.5-bridge.md` §1.5.7
- Legacy reference: `docs/roadmap/ROADMAP.md` §1.5.7 item 5
- Depends on: T-005.

## Acceptance criteria

- [ ] `nexora demo:clean --tenant=<slug>` CLI command wipes demo-seeded rows (identified
      by the `demo_seed_marker` table from T-005).
- [ ] `--drop-tenant` flag deprovisions the entire tenant schema (with confirmation
      prompt).
- [ ] Admin UI button mirrors the CLI (permission-gated).
- [ ] Cleanup is idempotent and safe to run on a tenant that has mixed real + demo data
      (only demo-marked rows are removed).
- [ ] Integration test covers mixed-data tenant cleanup.

## Technical notes

- Uses the sanctioned "module uninstall / orphan cleanup" hard-delete path (per
  CLAUDE.md soft-delete rules).
- Emits `TenantDeprovisionedIntegrationEvent` when `--drop-tenant` is used, for
  downstream modules to clean up tenant-scoped external state (MinIO buckets, Keycloak
  realm).
