## Context

Daily fetch of revocation list from `https://license.nexora.io/revocations.json`
with signed payload verification. Offline deployments receive bundle at next
license renewal.

See `docs/operations/license-and-helm-upgrade.md` §4.3.

## Acceptance criteria

- [ ] Recurring job `license:fetch-revocations` (daily 03:00 UTC).
- [ ] RSA-verify the signed bundle before merging into local revocation cache.
- [ ] Revoked licenses enter grace mode immediately if active.
- [ ] Offline deployments fall back to bundled revocations (no phone-home).
- [ ] Tests: signature tampering rejected, unchanged bundle is no-op.
