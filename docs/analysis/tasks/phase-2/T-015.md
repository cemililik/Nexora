## Context

Daily fetch of revocation list from `https://license.nexora.io/revocations.json`
with signed payload verification. Offline deployments receive bundle at next
license renewal.

See `docs/operations/license-and-helm-upgrade.md` §4.3.

## Acceptance criteria

- [x] Recurring job `license:fetch-revocations` registered for daily 03:00 UTC (`RevocationListFetchJob.RegisterRecurringSchedule` called from `IdentityModule.ConfigureJobs`).
- [x] RSA-SHA256 verification before any cache write (`RevocationListVerifier.Verify` over canonical bundle bytes).
- [x] `IRevocationListProvider.IsRevoked(string licenseId)` available for grace-mode short-circuit at any verifier site.
- [x] Offline mode skips HTTP — `RevocationListOptions.OfflineMode = true` reloads from the bundled file only.
- [x] Tests: 11 cases — signature-valid, tampered-entries, tampered-issuedAt, garbage-sig, wrong-key, empty-bundle round-trip; fetch-job persist + tampered-retains + unchanged-no-op + offline-skips-http + no-public-key-aborts.
- [x] 30s default `FetchTimeout` (`RevocationListOptions`).
- [x] Three exponential retries (1s/5s/30s) with ±25% uniform jitter (`TryFetchWithRetryAsync`).
- [x] Failed signature: bundle rejected, cache untouched, `LogError` so the on-call alert fires (verified by `ExecuteAsync_TamperedBundle_RetainsExistingCache`).
- [x] Atomic stage→rename — `File.Move(tempPath, cachePath, overwrite: true)` (POSIX `rename(2)` / Windows `ReplaceFile` — atomic).
