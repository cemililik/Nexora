## Context

Per ADR-0003, production migrations must be additive. An architecture test is needed
to enforce this mechanically — scan every `Migration.Up` method and fail CI on
`DropColumn`, `RenameColumn`, or narrowing `AlterColumn`. Without this guard,
regressions are only caught in review.

See `docs/operations/migration-orchestration.md` §1.2.

## Acceptance criteria

- [ ] `tests/Nexora.Architecture.Tests/MigrationTests.cs` with xUnit `[Fact]` per
      forbidden operation.
- [ ] Scans all `IMigration` implementations across modules.
- [ ] Fails with a clear message identifying the migration + line.
- [ ] Allowlist mechanism for intentional destructive changes (requires ADR).
