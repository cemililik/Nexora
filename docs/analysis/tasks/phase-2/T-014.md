## Context

Self-hosted deployments must hot-reload license files without a platform restart
when customers upload a new `.lic` via the admin portal or write to the secret
mount path. Needs a `FileSystemWatcher` (or K8s secret volume reload signal) that
re-validates and publishes a `license.refreshed` event.

See `docs/operations/license-and-helm-upgrade.md` §4.1.

## Acceptance criteria

- [ ] `LicenseService.ValidateAsync` triggered on file change at
      `/var/lib/nexora/license.lic` (or configured path).
- [ ] New license becomes active with no pod restart.
- [ ] Invalid file rolls back to previous valid license; admin alerted.
- [ ] Unit tests + integration test exercising file replacement.
