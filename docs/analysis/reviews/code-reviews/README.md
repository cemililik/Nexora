# Code Reviews

PR-level and comparative code-review findings. The legacy `docs/code-reviews/` folder
contains the historical artifacts (33 reviews as of Phase 1); new reviews live here.

## File naming

`YYYY-MM-DD-<pr-number-or-slug>.md`.

## Minimum sections

- **Context** — what PR / what module / what reviewer.
- **Findings** — numbered list with severity (Blocker / Major / Minor / Nit).
- **Follow-up** — tasks opened, ADRs proposed, standards updated.
